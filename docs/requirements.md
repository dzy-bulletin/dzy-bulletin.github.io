# 需求：鼎兆元｜電子佈告欄

- 版本：v1 / 2026-09-29
- 狀態：Eason 已確認（2026-09-29）
- 預覽：`preview/index.html`（本機假資料版，已經 Eason 看過並修改 3 輪）

## 1. 要解決的問題

集團要佈達的公告、重要事項，目前沒有一個固定地方可以查，也不知道誰看過。
要做一個**手機打開就能看**的電子佈告欄：

- 公告依單位分區顯示
- 附件只能看、不能下載
- 每則公告都永久留存，並依月份封存
- 知道每個人有沒有讀過，而且要留下本人的手寫簽名

## 2. 使用者

| 角色 | 怎麼進來 | 能做什麼 |
|---|---|---|
| 同仁（墨竹亭／小辛辣／央廚） | 打開網址 → 選單位、點自己的名字 → 輸入個人 4 位數密碼（第一次先設定） | 看公告、開附件、手寫簽名確認已讀、查歷史區 |
| 管理者（有管理通行碼的人） | 按「⚙ 設定」→ 輸入管理通行碼 | 新增／編輯／上架／下架／置頂公告；看已讀回條與簽名；管理同仁名單（新增、刪除、重設密碼）。管理通行碼只有 Eason 能在 Apps Script 更換 |

## 3. 核心功能（Eason 已定案，預覽已實作）

### 3.1 公告
1. 名稱「鼎兆元｜電子佈告欄」。
2. 分三區：**墨竹亭、小辛辣、央廚**。上架時勾選顯示單位，可選「全部」（三區都出現）。
3. 欄位：標題、內容、顯示單位、上架日、到期日（可留空）、置頂、附件。
4. **上架日在未來 → 排定上架**：到那天才會出現在同仁畫面。
5. **到期自動下架**：過了到期日自動移出公告區。到期日留空就不會自動下架，要手動下架。
6. **置頂**：排在最上面，並有明顯標記。
7. **沒有刪除，只有下架**：每則都永久留存。下架後可以重新上架（已過到期日的要先延後到期日）。

### 3.2 附件
8. 可以上傳 Word（.doc／.docx）、PDF、Excel（.xls／.xlsx）。**每則最多 5 個，單檔 20MB 以內**，超過就擋下來並提示原因。
9. 同仁**只能在手機上線上檢視，不能下載**。實測結果見第 5 節。

### 3.3 歷史區
10. 下架的公告依**下架日期的月份**封存：
    - 自動到期的，用到期日當下架日。
    - 手動下架的，用按下「下架」那天當下架日。
11. 同仁可以到歷史區，依單位、月份查詢，也可以開附件。

### 3.4 同仁身分與已讀回條
12. 同仁不用登入帳號，但要從**同仁名單**點選自己，並輸入**個人 4 位數密碼**：
    - 第一次使用時設定密碼，要輸入兩次；1111、1234 這類太好猜的會被擋。
    - **連續錯 3 次就鎖住，要主管重設密碼才能再用**（2026-09-29 拍板，取代原本的 5 次鎖 5 分鐘）。
    - 選名字頁的姓名遮住中間字（例：陳O安），管理端顯示全名。
    - 這支手機會記住身分，下次打開不用再輸入。
13. **忘記密碼**：只顯示「請主管到『設定 → 同仁名單』按『重設密碼』，你下次選名字時就能設定新密碼」。**沒有自助重設**。
14. 主管重設某人密碼後：舊密碼立即失效，那個人已登入的手機也會被登出。
15. **已讀回條**：
    - 同仁按「我已閱讀」→ 手寫電子簽名 → 確認，記下姓名、時間、簽名。
    - 管理端每則公告都看得到「已讀 X/Y 人」、誰讀了誰沒讀，以及每個人的簽名。
16. 應讀人數＝公告顯示單位內、目前名單上的同仁。
    - 刪除同仁後，他的簽名紀錄保留，但不再計入人數。
17. 未讀的公告有紅點，自己單位的分頁會顯示未讀則數。

### 3.4.1 總部同仁（2026-09-29 追加）
- 同仁名單除了墨竹亭、小辛辣、央廚，另有**總部**，分三組：總部鼎兆元、總部墨竹亭、總部小辛辣。
- **總部鼎兆元**看得到全部公告，但只需簽上架時選「全部」的公告。
- **總部墨竹亭／總部小辛辣**三個分頁都看得到，但只需簽自己品牌的公告（含「全部」）。（2026-09-29 改：原本只看得到自己品牌）
- 門市同仁維持原樣：三個分頁都能看，只簽自己單位的。
- 上架時可選的顯示單位不變（墨竹亭、小辛辣、央廚、全部）。

### 3.4.2 墨竹亭依門市選名字（2026-09-30 追加）
- 選名字時點「墨竹亭」先出現光復／金山／六張犁（有未指定者另列「未分店」），點門市才展開名字；其他單位不分門市。
- 從金山打卡系統同步來的同仁自動歸金山；新增墨竹亭同仁必須選門市，設定頁可換門市。

### 3.4.3 速度（2026-09-30 追加）
- 主管登入記住 7 天；同仁登入永久記住（密碼重設才失效）。
- 先顯示畫面再補資料：公告與名單都先用手機上次的資料顯示，背景更新。
- 名單另由「名單快照」分頁發布到網路的 CSV 讀取（不經 Apps Script）；後端名單結果以 CacheService 快取。

### 3.4.4 從 LINE 選單自動登入（2026-10-09 追加）
- **2026-10-09 Eason：從 LINE 選單進入佈告欄時，用打卡已綁定的 LINE 自動登入；對不到人退回選名字＋密碼。**
- 入口：「鼎兆元打卡」官方帳號的選單加「佈告欄」按鈕（LIFF）。同一個 LINE 對到多位同仁時，讓本人從遮罩姓名中選。
- 綁定資料直接沿用打卡系統 roster 的 `line_user_id`（佈告欄只存它的雜湊，不存原始 LINE userId），每小時與「打卡同步」時更新；打卡離職或解除綁定就失效。
- LINE 登入不受密碼鎖定影響、也不會改動密碼（LINE 本身就是另一個身分證明）；原本的選名字＋4 位數密碼照常可用。
- **解綁或改綁會踢掉已登入的手機**（2026-10-09 審查 #32-2）：打卡系統解除綁定、改綁別的 LINE、或打卡離職後，下一次同步（每小時或主管按「打卡同步」）會讓那位同仁的密碼版本 +1——所有已登入的手機（含用密碼登入的）都要重新登入；密碼本身不變。從沒綁到綁上不會踢人；某店名單讀取失敗時那店不動。
- **2026-10-09 Eason 接受（審查 #32-4）：信任來源變成打卡系統的「輸入全名綁定」。** 打卡系統第一次用 LINE 時輸入全名就能綁（防代綁只靠：人在該店 GPS 範圍、該名字還沒被綁、綁定紀錄可在值班核定頁解除）。所以同店的人在同事**還沒綁 LINE 之前**，輸入同事全名就能把自己的 LINE 綁到他身上，再從 LINE 選單以同事身分進佈告欄、替他簽已讀——**繞過同事已設好的 4 位數密碼**。風險等級與既有「還沒設密碼的名字誰都能先設」相同，但對象從「沒設密碼的人」擴大到「設了密碼、還沒綁 LINE 的人」。2026-10-09 Eason 接受；配套：①請各店主管督促全員儘速到店綁定打卡（綁定後無法被搶綁）②主管可在值班核定頁「LINE 綁定紀錄」查看與解除誤綁，解除後最慢一小時（下一輪同步）佈告欄同步登出。

## 6. 限制與風險（請 Eason 知悉）
1. **截圖擋不住**：「禁止下載」只能擋住下載、列印、複製，擋不住手機截圖或拍螢幕。
2. **代簽風險**：個人密碼加手寫簽名可以當作證據，但如果同仁把密碼告訴別人，系統分不出來是誰簽的。
3. **Drive 空間共用**：madesiaosinla 的空間滿了，佈告欄、現金帳照片等系統都會一起上傳失敗。
4. **管理通行碼只有一組**：看得到所有人的簽名。持有的人一變動，就要改通行碼。
5. **惡意鎖帳號**（2026-09-29 Fable 審查提出）：名單頁公開、登入不需其他憑證，所以知道網址的人可以對每個名字各輸錯 3 次，把全員鎖住，主管得逐一重設。這是「不登入＋連錯 3 次鎖到主管重設」兩個決定合起來的必然結果。目前網址只在內部流通，風險低；真的發生時，可以請我加「一鍵全部解鎖」或改成鎖定 15 分鐘自動解除。
